# 项目总览与整体架构

## 1. 项目是什么

CityAI Hub 是一个“类大众点评 + AI Agent”的本地生活服务平台。它保留了点评、优惠券、秒杀、支付等传统业务链路，并加入：

- 布隆过滤器防缓存穿透
- 滑动窗口限流
- RocketMQ 异步下单与延迟关单
- 分布式锁处理支付/关单并发
- Spring AI + 手写 Agent Loop
- Milvus 多向量集合 RAG
- MySQL 会话记忆
- SSE 流式输出

## 3. 分层职责

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 前端 | `frontend-vue/src` | 页面、Pinia 状态、Axios 请求、SSE 读取 |
| Controller | `src/main/java/com/hmdp/controller` | 参数接收、路由映射、结果包装 |
| AI Controller | `src/main/java/com/hmdp/ai/controller` | AI 会话、聊天、推荐、分析、索引重建 |
| Service | `service` / `service.impl` | 业务逻辑、事务边界、缓存/MQ 编排 |
| Utils/Component | `utils` / `component` | 缓存、锁、ID、限流、初始化器、事件监听 |
| Mapper | `mapper` + MyBatis-Plus | 数据库访问 |
| MQ | `mq` | RocketMQ 生产者/消费者 |
| AI Agent | `ai/agent`、`ai/tool`、`ai/rag` | Agent Loop、Tool Calling、RAG |

## 4. 关键启动过程

Spring Boot 启动后：

1. `BloomFilterInitializer`：异步预热店铺和优惠券布隆过滤器。
2. `SeckillStockInitializer`：把秒杀券库存从 MySQL 预热到 Redis。
3. `KnowledgeBaseInitializer`：检查 Milvus 三个向量集合，缺失则重建。
4. `CommonConfiguration`：创建三个 `VectorStore`，并在维度不匹配时按配置重建集合。

对应代码：

- `src/main/java/com/hmdp/component/BloomFilterInitializer.java`
- `src/main/java/com/hmdp/component/SeckillStockInitializer.java`
- `src/main/java/com/hmdp/ai/component/KnowledgeBaseInitializer.java`
- `src/main/java/com/hmdp/ai/config/CommonConfiguration.java`
