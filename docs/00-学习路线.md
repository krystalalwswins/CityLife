目标不是“跑起来”，而是能在秋招面试里讲清楚：架构、模块职责、四类请求链路、后端技术选型，以及 Agent 的真实实现。

## 三遍阅读法

第一遍：按请求链路读，不纠结细节，先建立“谁调用谁”。

第二遍：按技术主题读，重点看 Redis、RocketMQ、Spring AI、Milvus 这些关键实现。

第三遍：带着面试题读，尝试不看文档口述流程，再回到代码验证。

## 项目最重要的 4 条链路

- 普通业务：`ShopController -> ShopServiceImpl -> CacheClient -> MySQL`
- Redis 缓存：同上，但重点在 `CacheClient` 的穿透/击穿处理
- 秒杀：`VoucherOrderController -> VoucherOrderServiceImpl -> Redis Lua -> RocketMQ -> Listener -> MySQL`
- Agent：`AiAgentController -> AiAgentServiceImpl -> Event -> Listener -> AgentLoopExecutor -> ChatModel/Tool/RAG/SSE`

## 技术栈速记

- Java 17 / Spring Boot 3.2.4
- MyBatis-Plus 3.5.5 / MySQL 8
- Redis + Lettuce + Redisson
- RocketMQ Spring 2.3.3
- Spring AI 1.0.3
- Milvus 2.6.11
- Vue 3 + Pinia + Element Plus
